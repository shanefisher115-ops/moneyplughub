## What is Bolt.new?

Bolt.new is an in-browser AI-powered full-stack development environment that lets you prompt, build, run, and deploy production web applications instantly. By executing Node.js environments directly inside WebContainers, Bolt gives developers and creators the ability to turn text descriptions into fully functional web apps with zero setup overhead.

### Key Features
* **In-Browser Execution:** Run full Node.js backends and frontend frameworks natively in your browser.
* **Full-Stack Prompting:** Generate complete database models, API routes, UI components, and authentication flows.
* **One-Click Deployment:** Instantly push your generated applications to production hosting.
* **Integrated Package Manager:** Install npm packages on the fly directly inside your prompt sessions.
